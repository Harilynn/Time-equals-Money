# 🎮 QUICK START GUIDE - Market Simulation Mode

## 🚀 Launch the Application

### Development Mode (Recommended for Testing)
```bash
cd v0-time-is-market-game
npm run dev
```
Then open: **http://localhost:3000**

### Production Mode
```bash
cd v0-time-is-market-game
npm run build
npm start
```
Then open: **http://localhost:3000**

---

## 📖 How to Access Simulation Mode

1. **Start the application** (see above)
2. On the **title screen**, you'll see two buttons:
   - "Begin Your Life" (main game)
   - **"Try Simulation Mode"** ← Click this!
3. You're now in the Market Simulation!

---

## 🎯 Quick Tutorial

### Step 1: Choose a Scenario
**For Beginners:** Click **"📈 Persistent Bull Run"** (easiest)
**For Challenge:** Click **"🦠 COVID-19 Shock"** or **"🏚️ 2008 Financial Crisis"**

### Step 2: Configure Events
- **Toggle events ON/OFF** by clicking event boxes
- **Recommended for first try:** Leave all events ON
- **Select speed:** 2x or 4x for faster results

### Step 3: Launch Simulation
Click the big green **"🚀 Launch Simulation"** button

### Step 4: Watch it Run!
Observe:
- **Live price chart** updating in real-time
- **Market sentiment** swinging
- **Active events** triggering (shown with emojis)
- **Progress bar** showing days remaining

### Step 5: Review Results
After completion:
- See **final price change** (green = profit, red = loss)
- Check **event frequency** (how many crashes/booms occurred)
- Read **insights** for live market strategies
- Click **"🔄 Run Another Simulation"** to try different scenarios

## 🎨 Visual Guide

### Scenario Colors
- **🟡 Amber/Orange** = Historical Events (real market crises)
- **🔵 Blue/Cyan** = Abstracted Patterns (general behaviors)

### Event Indicators (During Simulation)
- **📈** = Boom event active
- **📉** = Crash event active
- **😱** = Panic event active
- **⚖️** = Regulation event active

### Result Colors
- **🟢 Green** = Profitable scenario (price went up)
- **🔴 Red** = Challenging scenario (price went down)

## 🔧 Troubleshooting

### Charts Not Showing?
- Make sure **recharts** is installed: `npm install`
- Refresh the page

### Simulation Runs Too Fast?
- Select **1x speed** instead of 2x or 4x

### Want to Start Over?
- Click **"← Back"** button at any stage
- Click **"← Back to Menu"** from results

### Performance Issues?
- Use **4x speed** for faster completion
- Close other browser tabs
- Reduce browser window size

## 📚 Understanding the Metrics

### During Simulation
- **Current Price**: Real-time market price (starts at $100)
- **Market Sentiment**: -100 (extreme fear) to +100 (extreme greed)
- **Volatility**: Daily price fluctuation % (higher = riskier)
- **Active Events**: Currently triggering market events

### In Results
- **Final Price**: End price of the simulation
- **Total Change %**: Overall profit/loss percentage
- **Max Drawdown**: Worst loss from peak to trough
- **Peak-to-Trough**: Total range of price movement
- **Final Score**: Performance score (higher is better)
